# Licences open source de Plum3

Plum3 utilise notamment Tauri, TypeScript, Vite, Serde, rfd, pulldown-cmark, printpdf et docx-rs.

Avant chaque publication, vérifier les versions réellement verrouillées dans `package-lock.json` et `src-tauri/Cargo.lock`, puis joindre les textes de licence exigés par chacune de ces dépendances. Ce document ne remplace pas les licences distribuées avec leurs projets respectifs.
